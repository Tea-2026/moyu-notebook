摸鱼笔记本 3.3.2
==================

启动
----
双击本文件夹里的 Moyu.exe。

默认全局快捷键：Ctrl + Alt + N
（如果被其他软件占用，会自动尝试 Ctrl + Alt + Space / Ctrl + Alt + J，
实际键位可以在 设置 → 记录 里看到。）

关闭窗口不会退出，会收进系统托盘；右键托盘图标可以退出。
开机启动在 设置 → 记录 里打开。

活动栏
------
最左侧是一条窄活动栏：

- 备忘：现有的记录都在这里，密码、网站也算备忘。
- 日记：可用。左边是小日历，下面是本月日记；点日子就跳过去写。
- 笔记：可用。按书、诗、题建文件夹，书下面还能再分章节。
- 计划：一个标题和一张很大的纸；左侧总览所有计划。
- 日程：可用。日、周、月、年四个视角；有时间的日程按上午 / 下午分。
- 纸篓：独立的纸篓页，按备忘 / 日记 / 笔记 / 日程分类，可恢复或彻底删除。
- 品牌鱼回到备忘；纸篓、上锁、设置在活动栏底部。
- 鼠标停在图标上会显示名称；在空页面按 Esc 也能回备忘。

日记
----
- 点「日记」进入；默认停在今天。点日历上的过去日期可以补写。
- 有日记的日子在日期下面有一个小点；今天有圈，选中的日子会填色。
- 关掉日历上的未来日期，不能提前写。
- 标题可以不写；正文会自动保存。
- 右上角可以导出这一天的 Markdown，或者删掉这篇（可以撤销）。
- 设置 → 数据 可以导出全部日记 .md；JSON 备份也会包含日记。
- 日记 Markdown 是明文，开了密码锁也只保护本机数据文件，不保护导出的 .md。

笔记
----
- 左侧是「全部笔记 / 未分类 / 文件夹」树，像书签一样可以一层层分。
- 点「写一条」在当前的文件夹里新建；标题可以不写，正文自动保存。
- 点「分类」右边的小加号建顶层文件夹；鼠标停在文件夹上，可以
  新建子文件夹、重命名、删除。
- 文件夹可以直接拖：拖到另一个文件夹中间变成子文件夹，拖到上 / 下边缘
  调顺序，拖到底部的「移到顶层」回到顶层。
- 删除文件夹不会删笔记：里面的笔记会移到上一级（顶层文件夹则移到未分类），
  还可以撤销。
- 每条笔记顶部有「来源」下拉框和页码 / 位置；来源可以随时改。
- 右上角可以导出这一条 Markdown，或者删掉（可以撤销）。
- 设置 → 数据 可以导出全部笔记 .md；JSON 备份也会包含文件夹和笔记。
- 笔记 Markdown 是明文，不受密码锁保护。

计划
----
- 左侧列出所有计划，按最近修改排序；点一条打开。
- 一个计划就是一个标题和一张很大的纸；正文自动保存，标题可以不写。
- 右上角可以导出这个计划 Markdown，或者删掉（进纸篓，可恢复）。
- 设置 → 数据 可以导出全部计划 .md；JSON 备份也会包含计划。
- 计划 Markdown 是明文，不受密码锁保护。

右键菜单
--------
- 备忘、笔记、计划、日程、日记和纸篓里的条目都可以右键。
- 备忘：打开、复制、置顶、移到纸篓。
- 笔记：笔记卡可以导出 / 删除；文件夹可以新建子文件夹、重命名、
  移到顶层、删除。
- 计划：打开、复制、导出 Markdown、移到纸篓。
- 日程：编辑、复制、删除；空白日期上右键可以直接新建。
- 日记：打开这天、复制正文、导出、删除。
- 纸篓：恢复、复制标题、彻底删除。
- 浏览器的默认右键菜单已关闭，不会出现返回 / 刷新 / 另存为 / 打印。
- 输入框 / 正文里右键是应用自己的剪切 / 复制 / 粘贴 / 全选 / 清空；
  空白处右键只留当前页面的「新建」和「设置」。
- 菜单支持方向键和 Esc。

日程
----
- 点「日程」进入，默认是当前月。顶部切换「日 / 周 / 月 / 年」。
- 左侧「近期」把今天和以后的日程按日期、时间由近到远排好；点日期进那天的
  日视图，点日程直接编辑。手机上点右上角的收件箱图标，打开全屏近期列表。
- 日视图分成「全天 / 上午 / 下午」三层；有时间的日程按 12 点分到上午或下午。
- 周视图周一到周日七列；月视图是一整月；年视图是十二个月块，按月列出所有日程。
- 点月视图 / 周视图里的日期进日视图；点年视图里的月份进月视图。
- 「新建」只要求标题和日期；时间可以不填，不填就是全天日程。
- 可以写地点、备注；提醒可以选不提醒、准时、提前 5 / 10 / 30 分钟、
  1 小时或 1 天。
- 桌面版在托盘里运行时，会通过 Windows 通知提醒；全天日程的「准时」按当天
  09:00 算。点通知会打开日程页。程序退出后不会响。
- 右上角 / 日视图的段落可以新建；删掉日程可以撤销。
- 设置 → 数据 可以导出全部日程 .ics；JSON 备份里也会包含日程。
- 日程 .ics 是明文，不受密码锁保护。

纸篓
----
- 活动栏底部的纸篓是独立页面，不再只是备忘的筛选。
- 备忘、日记、笔记、计划和日程删掉后都会先来这里；顶部按类型分。
- 每条可以「恢复」或「彻底删除」，右上角可以清空整个纸篓。
- 日记同一天已经有一篇时，恢复会提示，不会覆盖。
- 纸篓里的东西仍在 JSON / 加密备份里；彻底删除后才消失。
- 有密码记录（包括纸篓里的）且未上锁时，自动备份仍然暂停。

连接 / CLI
----------
- 设置 → 连接 → 新建凭证；勾「读取」和 / 或「修改」。
- 密钥会显示出来，可以复制；之后在列表里点「复制」也能再取。
- 密钥用 Windows DPAPI 按当前用户加密保存；名字能改，密钥不能改。换 Windows
  账户或换机器后旧密钥文件无法解密，删除重建即可。
- 凭证可以随时停用 / 删除；停用立即失效。
- 终端里设置环境变量 MOYU_API_KEY，然后运行：
    moyu --help
    moyu summary
  安装包默认把 %LOCALAPPDATA%\Programs\Moyu 加进用户 PATH；便携版
  可以手动把解压目录加进 PATH，或直接用 目录\moyu --help。
- API 只监听 127.0.0.1，程序退出就停止；库上锁时返回 423。
- API 不会返回密码内容；只返回密码记录的标题、账号、网址等元数据。
- 完整接口和 AI 用法见 docs\api.md。

筛选
----
列表顶部点「筛选」，可以按类型（全部 / 网站 / 密码 / 备忘）、标签、
只看置顶、有附件、最近 7 天组合筛选。选中的条件会变成小标签，点叉去掉。
左侧原来的标签栏已经删掉，标签选择收进了筛选面板。

右下角的小窗
------------
桌面版运行后，屏幕右下角（任务栏上方）会常驻一条很细的鱼尾。
按住鱼尾可以拖到桌面任意位置，靠近屏幕边缘会平滑吸附，位置会记住。
靠左右两侧时鱼尾是竖的，靠上下两侧时是横的，离开边缘会缩成圆形。
点一下会从鱼尾所在的位置展开，再收起时也缩回鱼尾；展开后按住顶部标题栏可以拖动小窗。
标题或正文里已经有字时，小窗不会自己收起；拖文字、链接、图片、音频过去也会展开。

- 空着的时候点「新建笔记」，写标题、备注、标签，Ctrl + Enter 收好；
  下方还可以选「备忘 / 网址 / 密码 / 日记 / 笔记 / 日程」。
- 拖进来不经过菜单：纯文字默认备忘，链接、图片、文件按内容收好。
- 网页图片和音频默认只存链接。
- 本地图片、音频、文件会复制到 %LOCALAPPDATA%\Moyu\files。
- 本地音频在笔记里点「打开文件」，用系统播放器打开。
- 托盘右键可以关掉「右下角小窗」，也可以「打开右下角小窗」。
- edge:// 内置页、PDF 阅读器不支持；网页播放器本身多数不能拖。

安装位置
--------
安装包：%LOCALAPPDATA%\Programs\Moyu（按当前用户安装，不需要管理员）
便携版：解压到你选的目录，例如 D:\App\Moyu

数据位置
--------
%LOCALAPPDATA%\Moyu\WebView2
%LOCALAPPDATA%\Moyu\files（本地附件）
%LOCALAPPDATA%\Moyu\native-settings.json（小窗开关）
%LOCALAPPDATA%\Moyu\credentials.json（凭证哈希、DPAPI 密文和前缀，不存明文密钥）
%LOCALAPPDATA%\Moyu\api.json（本地 API 端口，退出即删）
文档\摸鱼笔记本备份（普通内容、日记、笔记、计划和日程自动备份，删程序不会删）

数据不在安装目录里，卸载或更新程序不会删掉记录、日记、笔记、计划和日程。
设置 → 数据 可以导出 / 导入备份、导出全部日记 / 笔记 / 计划 .md、导出日程 .ics、
立即备份、打开数据 / 备份文件夹。
自动备份的 latest.json 可以直接导入；开了密码锁时会问密码。JSON 备份里
包含日记、笔记文件夹、笔记、计划、日程和纸篓里的内容。
每篇日记、每条笔记、每个计划右上角也可以只导出当天 / 单条；导出的 .md / .ics 是明文。
有密码且未上锁时，自动备份会暂停，避免在文档里留明文密码；开锁后恢复，备份为密文。
未上锁时手动导出的 JSON 是明文，含密码字段；日记 / 笔记 / 计划 Markdown 和
日程 .ics 始终是明文。
换设备请用 设置 → 数据 → 导出备份。

运行依赖
--------
- Windows 10/11 x64
- 安装包自带 .NET 8 运行时；从源码跑的开发版需要 .NET 8 Desktop Runtime
- Microsoft Edge WebView2 Runtime（当前 155.0.4283.62）
- Visual C++ 2015-2022 x64 运行库（系统已有）

如果打不开，优先安装：
1. Microsoft Edge WebView2 Runtime
2. 使用安装包，或自行安装 .NET 8 Desktop Runtime (x64)

卸载
----
1. 右键托盘图标退出摸鱼笔记本。
2. 安装包版：设置 → 应用 → 摸鱼笔记本 → 卸载；
   便携版：删除解压目录和快捷方式。
3. 如需彻底清除笔记、日记、笔记文件夹、计划和凭证，再删除
   %LOCALAPPDATA%\Moyu 和 文档\摸鱼笔记本备份。

安装包只安装程序本身；便携版解压即用，但两者都会使用上面的本地数据目录。
