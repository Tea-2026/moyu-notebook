# Changelog

## 3.3.1 - 2026-10-28

- The collapsed fish-tail mini window can now be dragged around the desktop.
- After dragging, it snaps to a nearby screen edge or leaves the free position.
- The position is saved in native settings and restored on the next launch.
- Expanding near an edge opens toward the available screen space.

## 3.3.0 - 2026-10-26

- Replaced the WebView2 browser context menu with a custom paper-style menu.
- Text fields now have cut / copy / paste / select all / clear.
- Blank areas show page-aware New and Settings actions.
- Added item menus for memos, notes, folders, plans, schedules, diary days, and trash.
- Kept the browser menu's Back / Refresh / Save as / Print out of the app.

## 3.2.0 - 2026-10-26

- Added a right-click menu for memos, notes, folders, plans, schedules, diary days, and trash.

## 3.1.0 - 2026-10-26

- Added the Plan space: a title and a large writing area, with a sidebar overview.
- Plans are included in JSON backup, encrypted vaults, imports, exports, trash, local API, and CLI.
- Added all-plans Markdown export.

## 3.0.1 - 2026-10-26

- Credentials can be copied again later; the key is encrypted at rest with Windows DPAPI.

## 3.0.0 - 2026-10-26

- Added independent Trash view.
- Added draggable note folders.
- Added the fish-tail new-type menu.
- Added local HTTP API, credential management, and the `moyu` CLI.
- Fixed the folder-drag drop veil.

## 2.8.0
